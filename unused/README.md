# Záloha původních statických souborů

Tato složka obsahuje původní lokální obrázky, které se používaly v době, kdy byly akce a profily vedoucích na webu spravovány čistě staticky:
- `akce/listecky/` – původní statické lístečky akcí
- `vedeni/foto_vedeni/` – původní profilové fotografie vedoucích

Veškerá nová i aktuální data jsou již dynamicky uložena a spravována ve **Firebase Storage** a databázi **Cloud Firestore**. Tyto lokální soubory slouží pouze pro vaši případnou zálohu a můžete s nimi naložit dle vlastního uvážení (ponechat či smazat).
